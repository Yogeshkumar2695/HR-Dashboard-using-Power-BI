**HR Analytics Dashboard – Power BI Project**
 
This project is an interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, workforce demographics, salary trends, and job satisfaction. The dashboard helps HR teams identify factors affecting employee retention and supports data-driven decision-making.
