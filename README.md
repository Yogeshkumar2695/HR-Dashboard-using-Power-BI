**HR Analytics Dashboard – Power BI Project**
 📌 **Project Overview**
This project is an interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, workforce demographics, salary trends, and job satisfaction.
The dashboard helps HR teams identify factors affecting employee retention and supports data-driven decision-making.

🎯 **Objective**

    The main objective of this project is to:
    •	Monitor employee attrition
    •	Analyze workforce trends
    •	Identify high-risk departments
    •	Understand employee behavior
    •	Improve employee retention strategies

🛠️ **Tools & Technologies Used**
    •	Power BI
    •	Power Query
    •	DAX (Data Analysis Expressions)
    •	Excel / CSV Dataset

📊 **Key KPIs**
    •	Total Employees
    •	Active Employees
    •	Attrition Count
    •	Attrition Rate
    •	Average Age
    •	Average Salary

📈 **Dashboard Features**
    •	Interactive HR dashboard
    •	Department-wise attrition analysis
    •	Employee age group analysis
    •	Gender distribution insights
    •	Job satisfaction analysis
    •	Salary trend analysis
    •	Dynamic slicers and filters

🔍 **Key Insights**
    •	Sales department showed the highest attrition.
    •	Employees working overtime had higher turnover.
    •	Younger employees experienced higher attrition.
    •	Lower salary groups showed increased resignation trends.
    •	Job satisfaction impacted employee retention.

🧹 **Data Cleaning & Transformation**
    Performed using Power Query:
    •	Removed unnecessary columns
    •	Handled missing values
    •	Corrected data types
    •	Created calculated measures using DAX
